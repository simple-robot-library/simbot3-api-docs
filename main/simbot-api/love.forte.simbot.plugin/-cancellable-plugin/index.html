CancellablePlugin

interface CancellablePlugin : Plugin(source)

表示一个可以被取消/终止的 Plugin。

取消的过程不可逆，当一个插件被取消后，不可再次回到活跃状态，且不应当再有任何状态改变或可用行为。 对于会产生各种副作用的行为，都应当抛出 PluginAlreadyCancelledException 异常。
