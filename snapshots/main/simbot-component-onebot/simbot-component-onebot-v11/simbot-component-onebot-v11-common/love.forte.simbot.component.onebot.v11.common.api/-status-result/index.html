StatusResult

@Serializable
data class StatusResult(source)

用于心跳事件中 status 属性和 get_status API 中响应数据的状态结果。

get_status-获取运行状态

status 在定义中存在 “OneBot 实现自行添加的其它内容” 的扩展字段。 这些内容可以考虑从事件的原始字符串或API响应的原始字符串中自行解析， 它的不确定性导致其难以直接通过 Kotlin Serialization 对其进行定义。
