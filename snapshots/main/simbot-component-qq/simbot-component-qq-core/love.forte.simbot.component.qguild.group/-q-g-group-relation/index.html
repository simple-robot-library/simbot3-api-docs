QGGroupRelation

interface QGGroupRelation : GroupRelation(source)

QQ组件中与QQ群相关的操作。 QQ平台尚不提供机器人已加入群的完整列表，因此：

  • groups 始终为空。

  • ID查询将是一种“伪”操作，会直接将提供的 id 包装为一个 QGGroup 返回。 如果此ID不是真实存在的，则进行某些操作时（比如主动发送消息）将会抛出异常。
