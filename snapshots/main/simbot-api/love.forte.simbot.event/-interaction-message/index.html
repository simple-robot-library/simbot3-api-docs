InteractionMessage

sealed class InteractionMessage(source)

拦截或通知中 SendSupport.send 或 ReplySupport.reply 的消息内容。

主要分为 标准类型 和 扩展类型.

Standard 用于表示三个标准库中提供的 Message 标准类型: 文本 Text, 消息 Message, 事件消息 MessageContent. Extension 用于当 Standard 无法满足组件需求时进行的额外扩展。
