EventDispatcher

interface EventDispatcher : EventProcessor, EventListenerRegistrar, EventListenerContainer(source)

事件调度器。 EventDispatcher 拥有 EventProcessor 和 EventListenerRegistrar 的职责， 是对事件调度、事件监听器管理的统一单元。
