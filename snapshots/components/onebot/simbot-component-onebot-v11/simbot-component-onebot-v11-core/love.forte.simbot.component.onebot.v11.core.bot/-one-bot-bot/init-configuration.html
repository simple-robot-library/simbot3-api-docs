initConfiguration

@ExperimentalOneBotAPI
abstract suspend fun initConfiguration(): Boolean(source)

根据 configuration 初始化部分配置信息。

在一些特殊情况下(例如测试或仅需要一些序列器等)， 如果希望在不 启动 bot 就初始化配置信息则使用此函数。

初始化配置只能执行一次。如果 isConfigurationInitialized 为 true 则会返回 false。 同一时间只会有一个 initConfiguration 被执行。如果出现竞争则会挂起， 直到其他竞争者完成初始化或出现异常。 如果其他竞争者完成初始化，则会直接返回 false，不会重复初始化。

start 中也会使用此函数。

NOTE: 未来标准库 Bot 中添加了 init 相关函数和属性后会被废弃。 参考 #1071

status

初始化状态有三个阶段：未初始化、正在初始化和完成初始化。 根据三个状态的不同，会影响 isConfigurationInitialized 和 isConfigurationInitializing 的值。

statusisConfigurationInitializingisConfigurationInitialized
未初始化falsefalse
初始化中truefalse
已初始化falsetrue

Return

如果已经初始化过了，则不会重复初始化，直接返回 false。 否则在成功初始化后返回 true。

Since

1.8.1

Throws

RuntimeException

初始化过程中出现的任何非预期异常。
